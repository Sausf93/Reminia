# 🔗 Enlaces de Reminia

Índice único de todos los enlaces útiles del proyecto. Guárdalo en marcadores.

> Los dominios `reminia.es` son los que ve el usuario. Las URL `*.pages.dev`
> (entre paréntesis) son las reales de Cloudflare; **no se renombran** porque
> romperían el CORS del backend — el usuario nunca las ve.

## Producción — lo que usan los centros

| Qué | Enlace | Notas |
|---|---|---|
| **Web pública / landing** | https://reminia.es · https://www.reminia.es | Puerta de entrada comercial |
| **Panel del centro** | https://panel.reminia.es | Maestra/integradora y admin *(real: `trazo-panel.pages.dev`)* |
| **Tablet / kiosco** | https://app.reminia.es | Para simular una tablet en el PC *(real: `trazo-tablet.pages.dev`)* |
| **Super-admin (Saulo)** | https://admin.reminia.es | Crear/bloquear centros, ver altas y pagos *(real: `trazo-admin.pages.dev`)* |

## Actividades

| Qué | Enlace | Contiene |
|---|---|---|
| **Probar actividades** (vitrina) | https://reminia.es → botón **«Probar las actividades»** | Una muestra bonita para enseñar el producto (sin emparejar) |
| **Validar actividades** (jugando) | https://app.reminia.es/pendientes-valoracion | Recorre las **pendientes por bloque**, las **juegas** una a una y las marcas Válida / Dudosa / No válida. Se guarda en el servidor |
| **Repasar aprobadas** (jugando) | https://app.reminia.es/actividades | Juega **todas las ya aprobadas** (filtro final, sin marcar) |
